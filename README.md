# Student Result Management System

A Python-based Student Result Management System developed using Lists, Dictionaries, Functions, OOP, CSV File Handling, and Exception Handling.

## Features

- Add student records
- Store student marks
- Calculate total marks
- Calculate average marks
- Calculate grades
- View all students
- Search students by ID
- Delete student records
- Store data permanently using CSV
- Input validation
- Exception handling

## Technologies Used

- Python
- Object-Oriented Programming
- Lists
- Dictionaries
- Functions
- CSV
- File Handling
- Exception Handling
